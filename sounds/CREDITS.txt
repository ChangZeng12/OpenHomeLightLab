Three packs, one folder each. Each pack uses the same cue mapping:

Pack folder   Panel name   Original family
soft/         Soft         packages/uisfx/sounds/soft
glass/        Elegant      packages/uisfx/sounds/glass
cinematic/    Epic         packages/uisfx/sounds/cinematic

error.mp3        <- error.mp3 (unchanged)
completed.mp3    <- complete.mp3 (unchanged)
receiving.mp3    <- press.mp3 (unchanged)
confirmation.mp3 <- select.mp3 (unchanged)
attention.mp3    <- press.ogg (two taps, second at 420 ms, 82% gain)
notification.mp3 <- hover.ogg (72% playback rate, 115% gain)
pairing.mp3      <- connect.mp3 (unchanged)
volume.mp3       <- press.ogg (115% playback rate, 65% gain)

Adaptations exported as 44.1 kHz mono MP3. These are exploratory
prototype cues, not a final OpenHome hardware sound specification.
